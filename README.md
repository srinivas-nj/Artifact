# Artifact

Welcome to my fourth web development project!

**Artifact** is a responsive web application built using **HTML5**, **CSS3**, and **JavaScript**. It enables users to enter their personal and professional information, preview their resume in real time, and generate a clean, professional resume.

## About the Project

This project was created to practice frontend development by combining responsive design with JavaScript functionality. It provides an interactive user experience for building resumes quickly and efficiently.

## Features

- Responsive Design
- Resume Creation Form
- Live Resume Preview
- Profile Photo Upload
- Education Section
- Skills Section
- Experience Section
- Projects Section
- Certifications Section
- Professional Links
- Print / Download Resume
- Clean and User-Friendly Interface
