# ATS Friendly Resume Guidance

ATS stands for Applicant Tracking System. It scans resumes for role-relevant keywords, structure, and formatting.

## ATS best practices
- Use standard headings such as Education, Skills, Experience, Projects, and Certifications.
- Prefer clean fonts such as Calibri, Arial, or Times New Roman.
- Avoid tables, text boxes, images, and complex graphics in the main resume body.
- Keep the resume simple and readable for both ATS and recruiters.
- Match keywords from the job description naturally in skills and experience sections.

## Keywords and formatting
- Include exact or close job description terms like Java, REST API, debugging, SQL, UI design, or problem solving when relevant.
- Use consistent spacing and bullet points.
- Save the resume as a PDF only if the company accepts PDF format.
- Ensure the file is not password protected or heavily styled.
