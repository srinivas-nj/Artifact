# Technical Skills

Skills should match the role you are targeting. Good resumes use a mix of technical depth and practical relevance.

## Common technical skills for CSE and IT resumes
- Programming: Java, Python, C++, JavaScript, TypeScript
- Web development: HTML, CSS, JavaScript, React, Node.js, Express
- Backend: Spring Boot, REST APIs, Firebase, PostgreSQL, MySQL
- Data structures and algorithms: arrays, stacks, trees, graphs, hashing
- Tools: Git, GitHub, VS Code, Postman, Maven, Linux
- Cloud and deployment: Docker, AWS, Azure

## Best practices
- Put the strongest and most relevant skills first.
- Divide skills into categories if the section is crowded.
- Include only skills you can speak about confidently.
- Add certifications or projects demonstrating those skills.
