# Internships

Internships should describe the work you did, the skills you used, and the outcomes you delivered.

## Good internship description format
- Role and duration
- Team or domain
- Core responsibilities
- Tools and technologies used
- Outcome or learning

## Example
- Worked as a Frontend Developer Intern, contributing to a responsive web application using HTML, CSS, JavaScript, and React.
- Improved page performance and UI consistency by refactoring reusable components and fixing accessibility issues.
- Gained hands-on experience in version control, team collaboration, and debugging production issues.

## Best practices
- Show initiative and ownership, not just day-to-day tasks.
- Include business or user impact when possible.
- If the internship was not directly related, focus on transferable skills like problem solving, teamwork, and communication.
